# campaigns

Campaign structures — campaign → ad group → keywords → ads — maintained by Claude as markdown or structured data (e.g., YAML/CSV).

Once live Google Ads API access is configured, these files represent the intended state of the live account, applied directly by Claude via the API. Until then, they're plans awaiting that connection — not manual-application instructions.

Suggested organization: one subfolder or file per campaign, e.g. `campaigns/brand-awareness/`, `campaigns/ocean-cleanup-programs/`.
