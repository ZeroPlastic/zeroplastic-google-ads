# keywords

Keyword research output: seed lists, match-type recommendations, and negative keyword lists, grouped by theme or campaign.

Suggested format: one file per campaign or theme (e.g., `keywords/ocean-cleanup.csv`, `keywords/negative-keywords.md`), with columns/fields for keyword, match type, and rationale.

Every keyword list here must pass the Ad Grants compliance checklist in [CLAUDE.md](../CLAUDE.md) before Claude applies it to the live account.
